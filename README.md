# Study MBBS Abroad Landing Page

This repository contains the code for a responsive landing page designed to attract potential students interested in studying MBBS abroad.  The landing page features information about the benefits of studying MBBS abroad, highlights top countries for MBBS programs, details the admission process and eligibility criteria, and includes a lead generation form.

## Technologies Used

*   HTML
*   CSS (Tailwind CSS)
*   JavaScript

## Features

*   **Hero Section:** Engaging banner with a call-to-action to apply now.
*   **Why Study MBBS Abroad:** Highlights key benefits of pursuing MBBS abroad.
*   **Top Countries:** Showcases popular destinations for MBBS programs (Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, Egypt, China, Malaysia, Germany, India - and easily expandable).
*   **Admission Process & Eligibility:** Outlines the steps involved in the application process and general eligibility criteria.
*   **Lead Generation Form:** Captures student information (name, email, phone, country preference) for follow-up.
*   **Responsive Design:** Optimized for viewing on various devices (desktops, tablets, mobile phones).
*   **Google Analytics Integration:** Tracks website traffic and user interactions.
*   **Facebook Pixel Integration:** Enables targeted advertising and conversion tracking.
